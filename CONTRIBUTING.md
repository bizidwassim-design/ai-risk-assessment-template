# Contributing

Thanks for helping improve this template. Welcome contributions: better scale descriptors, more precise ISO/IEC 42001
Annex A references, new fictional sample risks (especially for model types or sectors not covered), translations, and
corrections to the EU AI Act classifier where the regulation's text has changed.

## Ground rules

* **Fictional data only.** Example organisations are Northwind Logistics, Contoso and Fabrikam. No real clients,
  people, vendors, e-mail addresses, credentials or confidential incident details.
* **Standards by identifier.** Cite ISO/IEC 42001, ISO/IEC 27001, NIST AI RMF and the EU AI Act by clause, control ID
  or article; never paste their text.
* **No macros or add-ins.** The workbook stays a plain `.xlsx` that opens in Excel, LibreOffice Calc and Google Sheets.
* **Not legal advice.** Wording in the classifier must stay descriptive and hedged.
* Be kind — see the [Code of Conduct](CODE_OF_CONDUCT.md).

## How the workbook is built

`AI-Risk-Assessment-Template.xlsx` is generated by [`scripts/build_template.py`](scripts/build_template.py)
(Python + `openpyxl`). **Change the script, not the binary**, so every change is reviewable as a text diff.

```bash
pip install openpyxl
python scripts/build_template.py
```

## Making a change

1. Open an issue describing the problem or idea (optional for small fixes).
2. Fork and branch (`fix/severity-wording`, `feat/sample-risk-vision-model`).
3. Edit `scripts/build_template.py` and/or the Markdown docs.
4. Regenerate the workbook and open it. Check that:
   * no cell shows an error (`#REF!`, `#NAME?`, `#VALUE!`…) after a full recalculation;
   * empty register and inventory rows stay empty (no `0` or `#N/A` in formula cells);
   * drop-downs, conditional formatting, the summary counts and the dashboard charts still work;
   * text is Arial, inputs are blue, formulas are black on grey.
5. Commit the script change **and** the regenerated `.xlsx`.
6. Open a pull request describing what changed and why.

## Style notes

* Font Arial; navy headers; blue input cells; formulas black on light grey.
* Rating bands: Low 1–4, Medium 5–9, High 10–16, Critical 17–25 — the same as the sibling risk-register workbooks.
  Changing them means updating the register, the summary, the dashboard and the README together.
* Sample risks: one sentence of scenario, one of cause, roles not names, dates in 2026–2027.
